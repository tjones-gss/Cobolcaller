# Summary Prompt

## Objective
Provide a comprehensive summary of the program's functionality, flow, and business logic.

## Analysis Required

### High-Level Overview
- What is the primary purpose of this program?
- What business process does it support?
- When and how is this program typically invoked?

### Program Flow
- Describe the main execution path
- Identify key decision points and branches
- List major processing steps in order
- Note any loops or iterative processes

### Data Processing
- What are the input sources? (files, parameters, database)
- What are the output destinations?
- What transformations occur?
- What validations are performed?

### Dependencies
- What other programs does this call?
- What copybooks/modules/libraries does it use?
- What database tables does it access?
- What external systems does it interact with?

### Business Rules
- What calculations are performed?
- What validation rules are enforced?
- What error conditions are handled?
- What are the success/failure criteria?

### Technical Details
- Key data structures used
- Performance considerations
- Error handling approach
- Transaction boundaries (if applicable)

## Deliverables
- Executive summary (2-3 sentences)
- Detailed functional description
- Flowchart or pseudocode of main logic
- List of all dependencies with purpose
- Business rules documentation
- Known issues or technical debt

## Format
Structure the summary for easy reference:
1. Quick Summary
2. Detailed Analysis
3. Technical Notes
4. Recommendations (if any)
